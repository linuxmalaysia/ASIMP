About ASIMP

ASIMP is an automated framework built with Ansible to assess host compliance, configure OS parameters, secure SSH, and verify integrity.

Framework Engines

• Ansible: Playbooks and Roles orchestration
• OpenSCAP: Security profile checks (CIS Level 2)
• Lynis: Deep system configuration scanner
• debsums: MD5-based package integrity verification
